# Atividade: Configuração do Ambiente de Desenvolvimento

**Objetivo:** Configurar o ambiente de desenvolvimento para a disciplina de Programação Orientada a Objetos, utilizando **Java** e **IntelliJ IDEA**.

## Descrição

O aluno deverá realizar a instalação e configuração do **Java (JDK)** e do **IntelliJ IDEA**, criando um projeto Java e verificando sua execução.

Em seguida, deverá:

1. Mover a pasta do projeto Java criado para o repositório da disciplina;
2. Editar o arquivo `.gitignore`, incluindo a pasta `.idea`, para que ela não seja versionada no repositório;
3. Fazer o commit das alterações;
4. Abrir um **Pull Request** no repositório da disciplina.

> **Importante:** A pasta `.idea` não deve ser commitada no repositório.

A atividade deverá ser realizada de forma **autônoma**, utilizando **pesquisa na internet** e consulta às **documentações oficiais** das ferramentas.

## Entrega

Ao final da atividade, o aluno deverá apresentar:

- [ ] JDK instalado e configurado;
- [ ] IntelliJ IDEA instalado e configurado;
- [ ] Projeto Java criado e executado;
- [ ] Evidência da execução do projeto;
- [ ] Pull Request aberto incluindo o projeto no repositório da disciplina.
